# 下3トレーナー v1.0

下水道技術検定 第3種の後輩向けEラーニングです。

## 収録

- 令和7年度 第51回: 60問
  - 日本下水道事業団の公式問題PDFを正本として収録
  - 公式PDFをスマホ表示用のページ画像に変換
- 令和6年度 第50回: 60問
  - 実際に出題された問題の保存アーカイブを収録
  - 問1〜60と正答60問を照合
  - 正答不一致 0件

合計 **実過去問120問**。

## 学習機能

- 年度順演習
- ランダム20問
- 弱点だけ復習
- 年度別60問模試
- 3時間15分タイマー
- 分野別絞り込み
- 正答率・回答履歴
- 「覚えた / 怪しい / わからん」
- 端末内への進捗保存
- 進捗JSON書き出し
- iPhone / スマホ対応

## 正本構成

- `site_template.html` : v1.0画面テンプレート
- `r7_meta.json` : R7 60問の正答・解説メタデータ
- `r6_meta.json` : R6 60問の正答・解説メタデータ
- `r7_mondai_3syu_official.pdf` : R7公式問題PDF
- `r7_pages/` : R7スマホ表示用ページ画像
- `r7_page_map.json` : R7問番号→掲載ページ対応
- `r6_archive.html` : R6実問題保存版
- `r6_build_audit.json` : R6取得・正答照合監査
- `scripts/build_site.py` : index.html生成
- `scripts/validate_site.py` : 120問・出典資産・正答整合性検査

## 自動ビルド

GitHub Actionsは **Build and validate study site** の1本だけを正本とします。

処理順:
1. v1.0を生成
2. R7/R6各60問を検査
3. R7の60問ページ対応を検査
4. R6の60問・60正答・不一致0件を検査
5. JavaScript構文検査
6. PASSした場合だけ `index.html` を更新

旧v0.xの自動パッチ処理は削除済みです。

## R6について

日本下水道事業団は、多肢選択式の問題・正答について掲載期間を試験後おおむね1か月と案内しています。
そのため現在公式サイトでR6問題PDF本体を取得できず、保存されている実問題アーカイブを用いています。
似た問題や生成問題への置換は行っていません。
