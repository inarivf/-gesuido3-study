# 下3トレーナー v1.1

下水道技術検定 第3種の後輩向けEラーニングです。

## 収録
- 令和7年度 第51回: 60問
  - 日本下水道事業団の公式問題PDFを正本として収録
  - PDF上の「問○」位置を自動検出し、各問を1問単位で切り出し表示
- 令和6年度 第50回: 60問
  - 実際に出題された問題の保存アーカイブを収録
  - 問1〜60と正答60問を照合、不一致0件
  - 1問単位のHTMLに分割表示

合計 **実過去問120問**。

## 自動ビルド
GitHub Actionsは **Build and validate study site** の1本を正本とします。

処理順:
1. R7/R6の1問ビューを生成
2. v1.1サイト生成
3. R7 60問 + R6 60問を検査
4. 1問ビュー 60 + 60を検査
5. R6正答不一致0件を検査
6. JavaScript構文検査
7. PASSした場合だけ公開用ファイルを更新

## R6について
日本下水道事業団は、多肢選択式の問題・正答について掲載期間を試験後おおむね1か月と案内しています。
そのため現在公式サイトでR6問題PDF本体を取得できず、保存されている実問題アーカイブを用いています。
似た問題や生成問題への置換は行っていません。
