# 下3トレーナー

下水道技術検定 第3種の後輩向けEラーニングです。

## 内容
- 令和7年度・令和6年度の120論点
- ランダム20問
- 弱点だけ復習
- 暗記カード
- 60問模試（3時間15分）
- 端末内に進捗保存
- スマホ対応

## 2026年度試験
- 試験日: 2026年11月8日（日）
- 第3種: 13:15〜16:30
- 科目: 下水処理、工場排水、運転管理、安全管理、法規

## GitHub Pages公開
1. このリポジトリを Public にする
2. Settings → Pages
3. Build and deployment の Source を Deploy from a branch
4. Branch を main / root に設定して Save
5. 数分後に発行されたURLを開く
