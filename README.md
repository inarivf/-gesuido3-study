## v1.7の改善

- 同じ年度の前回模試から何点変わったかを表示
- 各模試の「この回の誤答を解く」から、間違えた問題だけ再挑戦
- 未回答問題と誤答問題を区別し、誤答復習に未回答を混入させない
- 模試の履歴と最終採点IDも学習履歴JSONへ保存・復元
- 古いv1.6以前の履歴JSONもそのまま取り込み可能

## 自動ビルド
GitHub Actionsは **Build and validate study site** の1本を正本とします。

処理順:
1. R7/R6の1問ビューを生成
2. v1.7サイト生成
3. R7 60問 + R6 60問 + R3 60問 + R2 60問を検査
4. R7/R6の1問ビュー 60 + 60を検査
5. R3/R2の問題文・4選択肢・正答60問を検査
6. JavaScript構文検査
7. PASSした場合だけ公開用ファイルを更新

## R6・R3・R2について
日本下水道事業団は、多肢選択式の問題・正答を一定期間掲載した後、掲載を終了しています。
そのため現在公式サイトで問題PDF本体を取得できない年度は、保存されている実問題資料を用いています。
R3は実問題保存ページの本文と、別サイトの第47回答え表を突合して60問一致を確認しました。
R2は第46回の実問題保存ページ（https://ameblo.jp/gensan2155/entry-12768003510.html）を収録しています。
保存ページの解答欄は問1〜30に限られ、問31〜60を含めた正答は別サイト（https://gesuidou.link/gesan46/）の第46回答え表を正本としました。
R2の詳しい解説文は現在未検証です。
似た問題や生成問題への置換は行っていません。
